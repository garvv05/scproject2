RouteEvolve — Soft Computing Viva Reference

1. How the Travelling Salesman Problem (TSP) Maps to Genetic Algorithms

The Travelling Salesman Problem asks for the shortest closed tour visiting N cities exactly once. Because an exhaustive search requires evaluating (N-1)! / 2 candidate tours (which becomes astronomically impossible for N ≥ 25), Soft Computing utilizes Genetic Algorithms to heuristically explore the combinatorial search space.

  • Chromosome: Path representation. A permutation of city indices [0, c1, c2, ..., cN-1] where city 0 is the fixed dispatch depot and the tour implicitly loops back to city 0.
  • Fitness Function: Fitness = 1 / Total_Route_Distance(km). Shorter distance produces higher fitness, naturally driving reproduction.
  • Distance Matrix: An N × N matrix precalculated with the Haversine spherical formula (or Euclidean plane metric) enables O(1) edge lookups and high-speed fitness evaluations.

2. Why Standard Single-Point Crossover Fails on TSP

Standard single-point crossover cuts two binary chromosomes and swaps the tails. In TSP, doing this causes severe duplicate cities and missing cities, breaking the permutation. Therefore, specialized operators like Order Crossover (OX) and Partially Mapped Crossover (PMX) are required:

  • Order Crossover (OX): Copies an intact subsegment from Parent 1 to preserve relative order, then fills remaining slots from Parent 2 cyclically without duplicating.
  • Partially Mapped Crossover (PMX): Uses cut-point mapping chains to preserve positional integrity.

3. Mutation Operators in TSP

  • Swap: Exchanges two random stops.
  • Inversion: Reverses a contiguous subsegment (mimics 2-opt edge untangling).
  • Scramble: Shuffles an internal sequence of stops.

4. Role of Elitism

Elitism copies the top E best individuals untouched into the subsequent generation. This guarantees the GA's best discovered solution is strictly monotonic non-increasing (it can never degrade due to random crossover/mutation disruption).
